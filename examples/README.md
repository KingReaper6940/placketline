# Practice outputs

These are invented geometric examples, not a garment pattern or recommended button layout.

- `project.json`: editable 600 mm practice band, eight centers, two interior pins.
- `receipt.json`: all exact positions, section gaps and tile ranges.
- `positions.csv`: complete center positions; import fraction columns as text.
- `overview.svg`: reference-size diagram only.
- `marking-a4.pdf` and `marking-letter.pdf`: four full-scale marking-strip pages each. Verify both calibration bars after printing at 100%.
- `dense.pdf`: fifty centers across 10 mm, deliberately demonstrating overlapping crosses and suppressed number labels. Not a practical sewing recommendation.

Run `npm run example` to regenerate all seven files. The README's output image is a Poppler rendering of the A4 PDF, not an application screenshot.
